# Clinical Care Consultants Landing Page

TMS lead-gen landing page for **Clinical Care Consultants** (Inverness, IL). Goal: qualified TMS inquiries and consultations.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- GoHighLevel form embed (`go.4tms.com`)

## Brand

Follows [clinicalcareconsultants.com](https://www.clinicalcareconsultants.com/) and the logo: leaf green (`#7DC242`), deep forest (`#395517`), cream (`#F9F7EE`), with Caudex + Lato + Satisfy (the fonts used on the live site). Tagline: "Counselors Who Care".

## CTAs (both primary)

- Find out if you Qualify → `#qualify` (GHL form `wnaOstwjn9uOhLYwdYXh`, rendered inline)
- Call → click-to-call

## Before launch

- Confirm conditions and insurance details to feature for TMS. The page makes no plan-specific claims, and only describes TMS for depression.
- Confirm how the AMPA device should be named in copy (`DEVICE_NAME`).

npm install
